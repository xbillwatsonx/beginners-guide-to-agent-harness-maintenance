# Prompt: Turn This Into My Own SOP

Copy this prompt into your agent chat.

---

Help me turn the Agent Harness Maintenance Runbook into my personal SOP (Standard Operating Procedure). Use what you know about my setup to fill in all the placeholders with my actual commands, paths, and service names.

Include:

1. **My baseline checklist** with real commands I can copy and paste.
2. **My backup command** with my actual paths.
3. **My update command** for my specific harness type and install method.
4. **My restart command** with my actual service or app name.
5. **My smoke test** with real checks that apply to my setup.
6. **My rollback plan** with real paths and commands.
7. **My maintenance calendar** with real days and times that fit my schedule.
8. **My first report-only cron job** with the exact command and schedule.

Save this as a file in my workspace. Name it something I will recognize, like `my-harness-sop.md` or `<harness name>-maintenance-sop.md`.

I should be able to open this file before any update and follow it step by step without thinking or looking anything up.

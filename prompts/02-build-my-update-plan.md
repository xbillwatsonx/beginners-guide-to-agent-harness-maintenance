# Prompt: Build My Update Plan

Copy this prompt into your agent chat.

---

Based on what you know about my setup, help me build a safe update plan.

Include:

1. **My harness type:** Local CLI, desktop app, WSL, VPS, or repo-based install.
2. **My current version:** The exact version I am running.
3. **My update command:** The exact command I should run to update. If there are multiple ways, recommend the safest one.
4. **My stop command:** How to stop the agent before updating.
5. **My start command:** How to restart the agent after updating.
6. **My backup command:** The exact command to back up my config and workspace before updating.
7. **My rollback command:** The exact command to restore from backup if the update fails.
8. **My verification commands:** The exact commands to run after updating to confirm everything works.

Use my actual paths and service names. Do not use placeholders. If you are unsure about any command, ask me before guessing.

Save this plan as a reference I can use before every update.

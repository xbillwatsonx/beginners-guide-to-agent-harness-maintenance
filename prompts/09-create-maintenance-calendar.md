# Prompt: Create Maintenance Calendar

Copy this prompt into your agent chat.

---

Help me create a maintenance calendar for my agent harness. I want to know what to check and when.

Based on what you know about my setup, recommend:

1. **Daily checks:** What should run every day? At what time?
2. **Weekly checks:** What should run every week? On which day? At what time?
3. **Monthly checks:** What should run every month? On which day? At what time?
4. **Update cadence:** How often should I check for updates? How often should I apply them?
5. **Backup schedule:** How often should I back up? When should I test restores?

For each item, include:
- What to check
- How to check it (the exact command or prompt)
- What "good" looks like
- What to do if it fails

Stagger the times so no two jobs overlap. Keep everything report-only for now.

Save this as my maintenance calendar. I should be able to look at it and know exactly what to do each day, week, and month.
